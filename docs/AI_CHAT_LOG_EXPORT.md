# Preserving the Original Codex Conversation

`AI_DEVELOPMENT_LOG.md` is a supplementary repository record. It is not the complete Codex transcript, and this workspace cannot verify or automatically capture every message shown in the Codex app.

To preserve the actual conversation for submission:

1. In Codex, open this task/conversation.
2. Use the app's available conversation export, copy, or share option. The exact menu label depends on the installed Codex version.
3. Save or print the complete conversation to a durable file (for example, a text/Markdown export or PDF) in the submission materials.
4. Open the exported file and confirm that it contains the full conversation and that formatting is readable.
5. Redact secrets, OTPs, session tokens, API keys, passwords, and sensitive personal information before sharing the transcript externally.
6. Keep the original unedited export securely if the submission requires an unredacted record; do not put it in a public repository.

If the current Codex version does not provide a complete export, copy the conversation messages into a document in order and verify it against the visible conversation. Label that document as a manually compiled transcript rather than an official complete export. Do not claim completeness unless you have checked it.
